Guide Utilisateur -- BibliothequeDB

Ce dépôt contient une application de gestion de bibliothèque fait 
en C# (.NET).
Elle permet de gérer les livres ,usagers et emprunts via une
architecture en couches (Domain, DataAccess, Business, App).

 Fonctionnalités :

-   Gestion des livres : ajout, modification, suppression et recherche.
-   Gestion des usagers.
-   Gestion des emprunts : creation, retour, consultation.
-   Accès aux données via SQL grâce aux repositories.
